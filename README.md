# ✨ Quote Generator API

A modern and minimal **Quote Generator Web App** built using **HTML, CSS, and JavaScript** that fetches real-time quotes from a public API.

Check it : https://arghyadip-17.github.io/synent-task6-apiintegrationproject-arghyadip/

---

## 🚀 Live Features

* 🔄 Fetch random quotes dynamically (API Integration)
* 📋 Copy quote to clipboard
* 🌙 Dark Mode / Light Mode toggle (with saved preference)
* ⏳ Loading spinner for better UX
* ❌ Error handling UI
* 🎨 Clean and responsive UI design

## ⚙️ How It Works

1. When the page loads, a quote is fetched from the API.
2. A loading spinner is shown while fetching.
3. The quote is displayed dynamically.
4. Users can:

   * Click **"New Quote"** → Fetch another quote
   * Click **"Copy"** → Copy quote to clipboard
   * Click **🌙 / ☀️ button** → Toggle dark/light mode
5. Theme preference is saved using **localStorage**.
